# 🚀 Adarsh Kumar Pandey — Personal Portfolio

A fully animated single-page personal portfolio website built with pure HTML, CSS, and JavaScript.

## ✨ Features
- Live particle network canvas animation
- Custom glowing cursor with trailing ring
- Hero section with shimmer gradient & 3D floating card
- Animated skill bars with IntersectionObserver
- Vertical timeline for experience
- Project cards with gradient sweep on hover
- Pulsing ripple contact section
- Fully responsive design

## 🛠️ Tech Stack
HTML5 · CSS3 · Vanilla JavaScript
